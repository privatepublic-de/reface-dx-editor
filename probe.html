MIDI ch = the DX's RV CH (FUNCTION, MIDI page). Notes and Program Changes go there. "Voice on the DX" follows the Program Changes the DX sends (TR CH), or set it by hand: the tests that switch Voices come back to it.

Reads Q1 Q4 Q11

a voice dump request with each number; which answer, and with which number?
e.g. 30 00 10 algorithm, 31 00 12 OP1 level, 00 00 0e MIDI control

Q4: change something on the DX's panel (an EG rate in Edit mode), then Read voice: does the dump list the change (edited voice) or not (stored voice)? Every read lists what changed since the last one.

Listen Q3 Q5 Q9

Click, then do one thing on the DX within the time: Q5 an FM-section knob (FREQ/LEVEL/ALGO/FB), then a parameter in Edit mode (EG, LFO, Pitch EG) or an effect; Q9 select another Voice; Q3 STORE a Voice to its own location (no change). Run Q5 once with MIDI Control on and once off. The summary lists what arrived.

DX settings Q11 · changes the DX's own settings

Parameter Changes to SYSTEM. Does each take effect at once (watch the DX's screen or FUNCTION page)? Read SYSTEM confirms.

Voice send Q2 Q4 Q6 · might write memory

Set "Voice on the DX" to a Voice you could lose. Send marked voice: selects that Voice (unstored edits on the DX are lost), reads it (kept as the original), changes its name to PROBE, Transpose +1 and OP1 Detune, sends all 7 blocks, logs what comes back within a second (echo) and reads it again (did it land?). PC away and back: does the mark survive a Program Change? If yes, the bulk was stored: then send the original back and PC away and back again.

Partial sends and rate Q7

Each test marks one value, sends only part of a voice, reads back whether it landed, then sends the whole original voice back. Read voice first.

Hold-note tests (listen: clicks, cut notes, retriggers). The voice is sent back afterwards.

Read all 32 Q8

Program Change, wait, dump request for each of 1-1 … 4-8, then selects "Voice on the DX" again. This replaces the voice being edited on the DX: afterwards, does FUNCTION → Job → EDIT RECALL bring an edit back? The voices go into the received SysEx (Download).

Frequency display Q10

Sets OP1 to the next coarse/fine/mode (or detune) by Parameter Change. Open OP1 in Edit mode on the DX, type what its screen shows, then Log. The log line carries what the editor would show, to compare. Send the original back afterwards.
